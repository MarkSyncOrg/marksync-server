MarkSync API

Encrypted bookmark sync service, compatible with the xBrowserSync API. Bookmark data is encrypted by the client; this service only ever stores ciphertext.

RouteDescription
GET /infoService status, version, location and maximum sync size.
POST /bookmarksCreate a new, empty sync. Body: { "version" }.
GET /bookmarks/{id}Get a sync's encrypted bookmarks, version and last-updated timestamp.
PUT /bookmarks/{id}Update a sync. Body: { "bookmarks", "lastUpdated"?, "version"? }. A stale lastUpdated is rejected with 409.
GET /bookmarks/{id}/lastUpdatedGet a sync's last-updated timestamp.
GET /bookmarks/{id}/versionGet a sync's data format version.
